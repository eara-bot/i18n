# Contributing

Contributing to this repository is a great way to help improve the experience of non-english speaking users that use Eara Bot. We welcome contributions in the form of translations and proof-reading.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and commit them using the [conventional commits](https://www.conventionalcommits.org/en/v1.0.0/) specification.
4. Push your changes to your forked repository.
5. Create a pull request to the main repository.
6. In the pull request description, include a summary of your changes and any relevant information.

Please keep in mind that we are looking for high quality translations, so please take the time to proof-read your changes before submitting them and make sure that they are consistent with the existing translations in the repository.

## Maintainers

Each language file has a set of owners / maintainers that will be responsible for reviewing and merging pull requests.

If you would like to become a maintainer for a specific language, please reach out to us through our [Discord Server](https://discord.gg/xKgKMAP).
